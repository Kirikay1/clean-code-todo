# Отчёт AI-ревью

Проверен `app.js` по категориям второй части задания. `index.html` и `style.css` использованы только как контекст для JavaScript и проверки сохранения поведения. Исходные файлы приложения не изменялись.

## Имена и читаемость

### Кнопка добавления определяется по позиции в документе

**Место:** `app.js`, строка 2.

**Проблема:** селектор `document.getElementsByTagName('button')[0]` означает «первая кнопка на странице», хотя имя `addTaskButton` означает конкретную кнопку добавления задачи. Связь между назначением переменной и способом поиска элемента неочевидна.

**Условие:** разработчик читает код без разметки рядом или добавляет другую кнопку выше кнопки `Add`.

**Проверка:** выбрать кнопку `Add` с помощью селектора, который прямо описывает её назначение, затем пройти пункт чек-листа «Новая задача добавляется в список Todo». Добавление должно работать как раньше.

## Функции

### Обработчики имеют скрытую зависимость от `this`

**Место:** `app.js`, функции `editTask`, `deleteTask` и `toggleTaskStatus`, строки 49–77.

**Проблема:** функции не принимают параметров, но могут работать только тогда, когда браузер вызывает их с элементом управления в качестве `this`. Эта зависимость не видна из сигнатур функций.

**Условие:** обработчик вызывается напрямую, передаётся через функцию-обёртку или регистрируется способом, который не сохраняет ожидаемое значение `this`.

**Проверка:** сделать элемент-источник события явным параметром обработчика и повторно пройти редактирование, удаление и перенос задачи между списками. Поведение не должно измениться.

## Именование

### Имя `editTask` описывает только одну из двух операций

**Место:** `app.js`, функция `editTask`, строки 49–65.

**Проблема:** имя `editTask` говорит только о редактировании, хотя функция переключает два состояния: начинает редактирование и сохраняет изменённый текст при выходе из него. Полное поведение функции нельзя понять только по имени.

**Условие:** разработчику нужно найти код, который сохраняет изменённый текст задачи, или изменить поведение кнопки `Save`.

**Проверка:** дать функции имя, отражающее переключение режима редактирования, обновить её привязку и повторно проверить редактирование задач в списках `Todo` и `Completed`. Поведение должно остаться прежним.

## Категории без замечаний

- **Мёртвый код:** не найден.
- **Дублирование логики:** оставшегося повторения, которое улучшило бы код после вынесения, не найдено.
- **Дублирование обработчиков:** каждый элемент управления получает один обработчик.
- **Комментарии:** в JavaScript нет комментариев, пересказывающих код.
- **Длинные функции:** естественных точек для дальнейшего дробления нет. `createNewTaskElement` выполняет одну задачу, не содержит ветвления и читается последовательно.
- **Поведение:** статический анализ не выявил изменений, противоречащих чек-листу; окончательная проверка выполняется вручную на деплое.
